# 界面国际化（i18n）施工计划

目标：界面能在**中文 / English** 之间切换，而不是把中文换成英文。版本落在 **0.4.0**。

盘出来的规模（2026-10-01 粗计）：

| 范围 | 数量 | 说明 |
| --- | --- | --- |
| 前端含中文的文件 | **57 个** | `wallpaper/src/**` 的 `.ts` / `.tsx` |
| 前端中文文案（粗计） | **约 974 处** | 最多的是 `settings/SettingsPanel.tsx`（294）、`App.tsx`（116）、`settings/SettingsWindow.tsx`（58）、`lite/LiteSettingsWindow.tsx`（47） |
| 原生含中文的字符串行 | **766 行** | `windows_integration.rs` 162、`chat.rs` 138、`lib.rs` 129、`importer.rs` 69、`deepseek_web.rs` 66、`harness_launch.rs` 49 —— **其中多数是日志**，但有一批会回到界面 |

## 一、机制（先定死，后面才不用返工）

1. **不加依赖**。一个字典模块 + 一个 `t()`，与这个代码库"纯函数优先、少依赖"的既有风格一致。
2. **词条分文件**：`src/i18n/zh.ts`（真源，现有文案原样搬过来）、`src/i18n/en.ts`、`src/i18n/index.ts`（`t` / `setLanguage` / `useLanguage`）。
3. **完整性由类型保证，而不是靠测试**：`en.ts` 声明为 `Dict`（由 `zh.ts` 推导出的类型），少一个键就**编译不过**。这比"跑测试才发现漏了"更早、更硬。
4. **语言是一份设置**：存进现有设置文档（`wallpaper/src/settings/store.ts`，需**升一次 version 并写迁移**），默认跟随系统（`navigator.language` 以 `zh` 开头取中文，否则英文）。
5. **非 React 代码也要能用**：`runtime.ts`、`connect/*` 里也返回面向用户的文案，所以 `t()` 不能是 hook。做法：模块级当前语言 + 订阅，React 侧用 `useLanguage()` 订阅重渲染。
6. **原生侧分两段处理**：
   - **先做**：界面已经在用**结构化状态**的地方（如桥的 `installed` / `already-present` / `failed`、可用性 `Offline` / `BridgeReady`），文案由**界面**按状态本地化，不再转发中文原文；
   - **后做**：原生**自由文本**（如 `未找到 DSH 壁纸 bridge token…`）——这一批要么改成**错误码 + 参数**由界面拼，要么明确记为"原生消息暂为中文"。**不假装它已经国际化**。

## 二、落点清单（按顺序做，每步都能独立验收）

| 步骤 | 范围 | 验收 |
| --- | --- | --- |
| 1 | 机制：`i18n/` 三件套 + `t()` + `useLanguage()` + 语言设置（含 store 迁移） | 切换语言后设置窗口立即变；typecheck 通过；store 迁移有测试 |
| 2 | 设置中心外壳：六个页签、页标题、状态栏、通用按钮 | 中英各截一次，肉眼可核对 |
| 3 | 设置中心各卡片（连接 / 外观 / 形态 / 历史 / 系统）—— **最大的一块**（294 处） | 同上；且词条键按 `settings.<tab>.<item>` 命名 |
| 4 | 桌面侧：`App.tsx` 气泡、提示条、会话窗、`ConversationBubble`（含 `Intl` 日期改用当前语言） | 切换语言后气泡与日期格式都变 |
| 5 | `lite/` 与 `connect/`、`native/runtime.ts` 的用户可见文案；原生结构化状态改由界面本地化 | 英文下不再出现中文提示 |
| 6 | 收口：**契约测试**（UI 文件里出现中文字符串字面量即失败，字典与测试文件除外）+ README 双语说明 + `docs/` 说明 | 测试能真的挡住新写死的中文 |
| 7 | 版本 0.4.0：四处版本号、构建、发布说明、release | 同 0.3.x 的流程 |

## 三、刻意的取舍（写在这里，免得日后被当成疏漏）

- **不做**"第三语言"抽象层（复数、性别、RTL 等）——两种语言、中日韩与英文，用最简单的键值就是对的。真需要时再抽。
- **不做**运行时加载语言包：词条编译进产物，少一次 IO、少一类失败。
- **不翻译日志**：日志是给维护者看的，保持现状（中文），只在 README 里说明。翻译它等于让 `grep` 失效。
- **原生自由文本**按第一节的第 6 条分两段，第一版允许它仍是中文，但**必须在 README 与 release 说明里写明**，不能让英文用户以为漏了。

## 四、与既有约定的关系

- 冻结/注释约定照旧（`archive/` + FREEZE 注释）；
- 中文文案**搬迁**而不是重写：`zh.ts` 里的值应当与今天界面上的字**逐字一致**，这样"中文界面没有变化"是可以验证的（对比截图）；
- 新增的**英文文案**是写出来的，不是机翻；
- 提交信息：英文、叙事、带证据（沿用本仓库既有风格）。
