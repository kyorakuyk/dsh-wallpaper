# DSH Wallpaper 0.3.1（完整版 · Windows 11）

修一个 0.3.0 里的缺陷：**设置窗口里"选中主体后自动对齐桥"这条命令从未被允许调用**。

## 症状

在 0.3.0 上打开设置，会看到一句提示：

```
装桥失败：Command ensure_profile_bridge not allowed by ACL
```

这不是文件权限问题，而是应用自己的**能力清单**（Tauri 的 capability ACL）里漏登记了这条新命令——
每个窗口能调哪些命令要在清单里逐条列出，而它两处都没写。

**桥本身没受影响**：真正装桥的是**启动时**那条路，它在原生侧、不经过这个清单，
所以 0.3.0 上选中主体后照常能用；出问题的只是设置窗口那一次尝试与那句反馈。

## 这一版改了什么

补齐能力系统要求的两半：命令的权限文件，以及**只在设置窗口**那份清单里的授权条目
（后台窗口与 Lite 版都不授权，与命令自己的门一致）。

## 装之前

- **系统**：Windows 11（需要 WebView2，Win11 自带）
- **安装器未签名**：第一次运行会有 SmartScreen 提示，点「更多信息」→「仍要运行」
- **harness 模式**需要有 DSH**（官方客户端，或 `npm i -g @deepseek-ai/dsh`）；桥由壁纸自己装进需要的档案

（其余功能与限制同 0.3.0，见那一版的发布说明。）
