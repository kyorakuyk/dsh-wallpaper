# DSH Wallpaper 0.4.1（完整版 · Windows 11）

修 0.4.0 里三处**在明面上出错**的地方：切了语言桌面不变、顶栏在英文下溢出、以及按你的要求停用计价与
tokens 读数。

## 修了什么

**语言选择只在"切换那一刻"生效**（0.4.0 的问题，已被你当场发现）

- 设置窗口与壁纸窗口是**两个独立运行时**，而 `setLanguage()` 当时只有一处调用——设置里那个下拉。
  于是切到 English，**只有设置窗口变**；输入岛、气泡、会话窗、日期**仍是中文**；
- 更糟的一半：**没有任何地方在启动时应用设置里的语言**，所以**重启后选择直接丢失**，又回到中文。

现在语言**由设置推导**：两个窗口都订阅它，任一处切换另一处立刻跟上；重启后照旧生效。
**必须说明**：这两处**目前没有回归测试**，是靠人眼看出来的——补测试是接下来该做的第一件事。

**顶栏在英文下溢出**

中文 `未提供` 对英文 `Not reported`，顶栏那行长约两倍，而里面的元素**没有一条收缩规则**：内容放不下
又不动，直接越过圆角，把右侧 Bridge 状态裁掉。现在**可换行、可收缩**，并且**换行优先于截断**（数字
与状态占两行仍可读，被切掉一半的单词不可读）。中文本来一行放得下，排布不受影响。

**计价与 tokens 读数停用**（按你的要求）

- 顶栏的"本轮 入/出/缓存/费用"与"会话费用"；
- 每条消息下方的"输入 · 输出 · 缓存 · 费用"；
- 设置 → 连接里的两个**价格输入项**，以及那句"配置后才会显示估算费用"的说明（那句话当时已成假话）；
- 页脚宿主徽章里"谁付钱"那半句（`你自己的 DeepSeek API key。` / `DeepSeek 网页额度。`）。

**全部是就地冻结，不是删除**：代码留在原处、注释写明**为什么关 / 关掉后什么变了 / 怎么恢复**，
词条一条未删，被删掉的原文逐字留档。**设置里的价格字段与迁移一行未动**——恢复只是取消几行注释。

**有意保留的一处**：设置 → 连接里仍有一句 **「API 模式会产生实际费用，密钥只保存在 Windows 凭据
管理器。」**。它是**风险提示**而不是读数，也没有说假话，所以按决定留下——免得读者以为漏了。

## 界面语言（0.4.0 起）

设置中心 → **常规** → **语言** → 简体中文 / English。**默认中文**（升级不会替你换语言）。

**原生（Rust）返回的自由文本仍是中文**：开机自启的原因、桥与宿主报回的错误原文等。这是计划内的
第二批，英文界面下这几处会看到"英文外壳 + 中文内文"。

## 安装与升级

到 [Releases](https://github.com/kyorakuyk/dsh-wallpaper/releases) 下载
`dsh-wallpaper_0.4.1_x64-setup.exe` 双击即可：**当前用户、不请求管理员、不需要证书**，卸载走
「应用和功能」。安装器未签名，第一次运行会有一次 SmartScreen 提示（更多信息 → 仍要运行）。

从 0.4.0 升级：直接装，覆盖即可；设置、素材、桥令牌都在原处不动。
