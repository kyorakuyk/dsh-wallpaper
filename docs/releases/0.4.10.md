# DSH Wallpaper 0.4.10（完整版 · Windows 11）

设置中心整体改版：从"通用深蓝玻璃面板"换成跟着角色走的样子。这一版**只改了设置中心的呈现**：设置项、保存方式、原生命令都没有变。

## 变了什么

**强调色跟随当前角色**：Harness 模式是暗红，DeepSeek 模式是海蓝。选中的导航、开关、按钮、焦点框都跟着变，切换聊天模式后立即生效。

**侧栏顶部换成当前角色的小立绘**，下面写着连接状态（在线是绿点，连接中是黄点，离线是灰点）。原来侧栏底部那一行状态挪进了这里。

**分区改成分组面板**：每个分区的设置项装在同一块纯色面板里，分区标题放在面板外面、放大一号。原来分区标题和设置项标题只差 1px，一页看下来分不清哪几项是一组。

**内容跟着窗口铺满**：之前内容区有固定最大宽度，拉宽窗口后右边会空出一大片，滚动条也停在中间。

**多屏设置改成显示器示意图**：两块屏按 Windows 里的真实排列和比例画出来，立绘和对话窗在哪块屏直接标在图上。点一块屏就能给它单独换背景。"立绘""对话窗"所在屏幕改成了"主屏 / 副屏 N"两段按钮，不再是"显示器 1 / 显示器 5"下拉框。"识别屏幕"会在示意图上标出编号，编号和屏幕名一致。

**外观页顶部加了实时预览**：背景、立绘、气泡放在一起，换背景、调环境强度都能直接看到。这是**近似效果**，以桌面实际显示为准。

**其他**：

- 字号整体调大，说明文字从 10px 提到 12px，颜色提亮到能看清；全设置中心不再有小于 11px 的字。
- 导航图标换成统一的线性图标。
- 改完设置后，状态栏会出现约 1.6 秒的"已保存 ✓"。
- 设置窗口底色改为不透明，背后的窗口内容不会再透出来。
- 切换页面时自动回到页面顶部。
- 下拉菜单离底部太近时会改成向上展开。
- 所有可交互元素都有键盘焦点框；系统开启"减少动画"时，设置中心的过渡动画会关闭。

## 没做的（留待以后）

- 外观页的"脚底阴影""呼吸动效"开关：壁纸本身还没有这两个功能。
- 在真实屏幕上弹出编号的"识别屏幕"：目前只在示意图上标编号。
- 侧栏和预览只用官方默认立绘，还不读你在素材库里替换过的立绘。
- Lite 版设置窗没有跟着改。

## 仍然是中文的那部分（不变）

原生返回的自由文本（开机自启原因、桥/宿主错误原文）在英文界面下仍可能是中文，与 0.4.0 起的说明一致。

## 怎么验

1. 打开设置中心，在「连接」页把聊天模式在 DeepSeek 与 Harness 之间切换：选中的导航、开关、按钮应当在海蓝与暗红之间跟着变，侧栏顶部的立绘也跟着换；
2. 用默认窗口大小看「连接」页：「运行方式」「网页适配」这类带下拉框或多个按钮的行，控件应当排在说明文字下方，按钮文字不再一字一行；把窗口拉宽，这些行回到左右排列，右侧不留空白；
3. 两块屏时，「常规」页的多屏示意图应当与 Windows「显示设置」里的排列一致；点一块屏、选一张背景，桌面上对应那块屏随之变化；
4. 在「外观」页换一张背景，顶部预览立即跟着变；
5. 任改一项设置，状态栏出现约 1.6 秒的「已保存 ✓」。
