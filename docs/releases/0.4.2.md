# DSH Wallpaper 0.4.2（完整版 · Windows 11）

壁纸现在**会发现自己过期了**，并且能在桌面上一路更新到新版本。

## 新功能：更新检测

**它会做什么**

- 启动后进入**里桌面**时检查一次 GitHub Releases 上的最新版本（**6 小时内只查一次**，不反复打网络）；
- 有更新时，**立绘上冒出气泡**：「有新版本 x.y.z」+ 两个按钮 **「下载」** 与 **「忽略」**；
- 点「下载」→ 气泡变成**进度条** → 下完变成「点击安装」→ 点了之后**交给 Windows 的安装向导**（新版是 NSIS 的 `setup.exe`；将来若是 MSIX，会交给 App Installer，两条路都在）；
- **设置中心 → 系统** 里有同一张卡片：当前版本、**上次检查的结果与原因**、以及一个「检查更新」按钮（手动检查**不受** 6 小时限制）。

**它的规矩（有意如此）**

- **点一下气泡不会升级**——必须明确点「下载」或「忽略」；
- **没点过不等于忽略**：关掉再开，气泡还是会来；只有按下「忽略」才会记住那个版本（**更晚的版本仍会提示**）；
- 气泡**只在里桌面出现**，唤醒动画与表桌面阶段不打扰你；
- **不在检查时偷偷下载**：只有你点了「下载」才会开始下；
- 下载会**校验**：大小不符、或（API 给了摘要时）sha256 不符，就**删掉文件**并告诉你原因；**认不出摘要形状时只核大小**——宁可放过，也不让人永远装不上；
- 失败原因是**可读的**（网络 / HTTP 状态 / 写入 / **磁盘空间不足** / 大小不符 / 摘要不符），并且保留「打开发布页」这条回落。

**它是怎么知道"当前版本"的**：按安装形态分派——打包态读包版本；**NSIS 装法读注册表卸载项的 `DisplayVersion`**，再退到主程序 exe 的版本串。**三条都读不到就不检查**，而不是猜一个版本。

## 其他

- 版本号从 0.4.1 升到 **0.4.2**。

## 已知边界（写在这里，而不是等你自己撞上）

- **那条链路的最后两步（真的发一次网络请求、真的拉起安装向导）没有自动化测试**——它们由单测覆盖到"逻辑"，但请求与 `ShellExecuteW` 这两段胶水只有真机能验。这一版发布前后会在真机上走一遍并记录结果；
- **下载没有"取消"**：开始后只能关掉壁纸；同一时刻只会有一个下载在跑；
- **重启不恢复"已下载"**：重启后气泡回到「有新版本」，需要再点一次下载（已下过的文件会被覆盖）；
- 下载中断会留下一个 `.part` 临时文件，下次下载会覆盖它（**半截文件永远不会顶着安装包的名字**——只有校验通过才会改名）；
- **原生返回的自由文本仍是中文**（英文界面下少数几处会看到中文内文），这是 0.4.0 就说明过的第二批。

## 安装与升级

到 [Releases](https://github.com/kyorakuyk/dsh-wallpaper/releases) 下载
`dsh-wallpaper_0.4.2_x64-setup.exe` 双击即可：**当前用户、不请求管理员、不需要证书**，
卸载走「应用和功能」。安装器未签名，第一次运行会有一次 SmartScreen 提示（更多信息 → 仍要运行）。

**从 0.4.0 / 0.4.1 升级**：直接装，覆盖即可；设置、素材、桥令牌都在原处不动。
从这一版起，也可以什么都不做——等到有更新时，壁纸自己会在桌面上问你。
