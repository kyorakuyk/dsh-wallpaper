# DSH Wallpaper 0.3.0（完整版 · Windows 11）

桌面壁纸加输入岛：鲸鱼娘在桌面上睡着、醒来；滑槽唤出输入岛，可以和 DSH（DeepSeek Harness）会话、
DeepSeek 网页版、或你自己的 API Key 对话。

## 装之前请先读这三条

**系统**：Windows 11（需要 WebView2 运行时，Windows 11 自带）。

**想用 harness 模式**：机器上得有 DSH —— 官方桌面客户端，或 `npm i -g @deepseek-ai/dsh` 装的 CLI。
桥（把壁纸和 DSH 接起来的那个插件）由壁纸自己装进需要的档案，装不上时设置里会说清原因；
如果 DSH 提示某个插件不兼容、需要"精确版本豁免"，那一步要你自己确认（壁纸不代你点）。

**安装器没有代码签名**：第一次运行会出现 Windows SmartScreen 的提示（「Windows 已保护你的电脑」）。
点「更多信息」再点「仍要运行」即可。这是未签名安装器的必然代价，不代表安装包有问题。

## 这一版的改动

- **壁纸不再触碰锁屏**。整块功能退出：它做的事和用户自己去 Windows 设置里换一张没有区别，
  却多出风险，而且不能回滚。系统集成暂时只保留**开机自启**。
- **安装方式换成普通安装程序**：当前用户安装、不请求管理员、不需要任何证书；卸载走「应用和功能」。
- **开机自启**通过注册表 `HKCU\Software\Microsoft\Windows\CurrentVersion\Run`，指向固定安装路径 ——
  不像过去那样每次升级换一个带版本号的目录。
- **桥自动对齐**：每次启动、以及选中主体时各检查一次；版本相符时**不跑包管理、也不动你的档案**。
- 输入岛左下角显示当前对话的**宿主**：Web / API / Desktop / TUI。
- 版本号从 `0.2.0.<构建号>` 改为 **0.3.0**。

## 已知限制
