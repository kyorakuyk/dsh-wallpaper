# DSH Wallpaper 0.4.0（完整版 · Windows 11）

界面现在**会说两种语言**：简体中文与 English。

## 怎么切

设置中心 → **常规** → **语言** → 选 English，界面立刻变，选择会保存。

**升级后仍然是中文**（有意如此）：升级不该在你眼皮底下把界面换一种语言；英文用户自己切一次即可。

## 这一版做了什么

**一套语言机制，而不是两种语言的复制品**

- 界面文案全部搬进词条（中文 682 条 / 英文 682 条），**中文与原界面逐字一致**——所以"中文用户看不出变化"这句话是可以验证的；
- **完整性由类型保证**：英文词条以中文的键为准声明，**少一条或多一条都编译不过**，不靠人工核对；
- 一条**契约测试**盯着"界面源码里不许出现中文（注释与日志除外）"，迁移期间它是一份只能变短的待迁清单，现在是空的。

**语言是一份设置**

- 存在设置文档里（版本 10 → 11，一条迁移）：默认中文，非法值回落，**迁移只补新键、不动你其它设置**；
- 日期与排序也跟着语言：中文 `3月5日周四` / 英文 `Thu, March 5`；主题与素材名在英文下按字母序。

**两处顺带修掉的缺陷**（中文下看不出来，切语言才会踩到）

- **存进状态的句子**：过去有一些提示/错误在"写进状态"时就把那句话渲染成字符串了——字符串一旦存下就是数据，固定在当时那种语言上。现在状态里存的是**键与参数**，显示时才渲染；
- **异常**：过去 `throw new Error(那句话)`、捕获处再 `String(error)`，同样会把语言钉死；现在异常携带**没求值的那句话**（连 `String(error)` 都能读到当前语言）。另外有两处"靠**文字**判断这是什么错误"的逻辑，改成看**标志**——按文字判断在英文下必然失效。

## 已知限制（这一版有意保留）

**原生（Rust）侧返回的自由文本仍是中文**。

具体地说：开机自启的"原因"、桥与宿主报回的错误原文、部分诊断句——这些由原生产生、原样显示。所以在**英文界面**下，你会看到"英文外壳 + 中文内文"的少数几句。

这是**计划内的第二批**（把原生的句子降成错误码、由界面自己说），不是遗漏；这一版的英文界面其余部分不含中文（我们有契约测试盯着）。

## 安装与升级

到 [Releases](https://github.com/kyorakuyk/dsh-wallpaper/releases) 下载 `dsh-wallpaper_0.4.0_x64-setup.exe` 双击即可：**当前用户、不请求管理员、不需要证书**，卸载走「应用和功能」。

安装器未签名，第一次运行会有一次 SmartScreen 提示（更多信息 → 仍要运行）。

从 0.3.x 升级：直接装，覆盖即可；设置、素材、桥令牌都在原处不动（设置文档会自动迁移，语言默认仍是中文）。

**Harness 模式**需要机器上有 DSH（官方客户端，或 `npm i -g @deepseek-ai/dsh`）；桥由壁纸自己对齐，遇到"版本豁免"提示时**要你自己确认**——壁纸只转达。
