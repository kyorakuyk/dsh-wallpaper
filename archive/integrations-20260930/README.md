1. `git mv` 回 `desktop_fallback.rs`（见上文），把 `lib.system-integration-commands.rs` 里的 `mod desktop_fallback;`、
   桌面底图命令（连同其 `///` 文档注释，放在 `lite_image_resolve` 之后、`mod lite_asset_tests` 之前）与 TranslucentTB 段
   （放在 `autostart_status` 之后）按上面的原位置放回 `lib.rs`。

   功能需要哪个窗口调用，就在对应的 `capabilities/*.json` 里显式授予 `allow-…`。
